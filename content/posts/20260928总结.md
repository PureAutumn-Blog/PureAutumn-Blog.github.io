:::success[]{open}
- 估分：$\color{green}100$

  赛时做法：注意到是一道基于可行性的最值问题，所以考虑二分答案。发现 $check$ 直接 $\operatorname{bfs}$ 即可。
  复杂度：$O(n \hspace{+.1cm} \log \hspace{+.1cm}maxw)$

```cpp line-numbers
#include<bits/stdc++.h>
#define ll long long
#define IOS ios::sync_with_stdio(0);cin.tie(0);cout.tie(0)
using namespace std;
const int INF = 1e9;
const ll LL_INF = 1e18;
int n, w;
int main() {
    IOS;
    freopen("collect.in", "r", stdin);
    freopen("collect.out", "w", stdout);
    cin >> n >> w;
    vector<int>va(n + 1);
    vector<vector<array<int, 2>>>ve(n + 1);
    for (int i = 2;i <= n;i++)cin >> va[i];
    for (int i = 1;i < n;i++){
        int u, v, w;
        cin >> u >> v >> w;
        ve[u].push_back({v, w});
        ve[v].push_back({u, w});
    }
    
    auto check = [&](int k){
        queue<array<int, 2>>q{};q.push({1, 0});
        ll sum = 0;
        while(!q.empty()){
            auto frt = q.front();q.pop();
            int fa = frt[1], now = frt[0];
            sum += va[now];
            for (auto p : ve[now]){
                if(p[0] == fa)continue;
                else if(k >= p[1])q.push({p[0], now});
            }
        }
        return bool(sum >= w);
    };
    
    int l = 0, r = 1e9;//二分武力值
    while (l < r) {
        int mid = (l + r ) / 2;
//        cout << l << ' ' << r << ' ' << mid << '\n';
        if (check(mid)){
            r = mid;
        }else l = mid + 1;
    } 
    cout << l << '\n';
    return 0;
}
```

    - $O(n \hspace{+.1cm} \log \hspace{+.1cm} n) \color{#3498db}提高+/省选−$
      :::
      做法：dp。
      :::info[$O(n^2)$ 题解]
      可以把题目转换为：给定一个序列 $a$ 将其分成无数段，求对于所有第 $i$ 段所有元素之和乘以 $i$ 再每一段的最大值减去最小值的最小值。

更加形象化的说：就是下图被涂色的矩形的面积之和加上上面每一段颜色内的最大值减去最小值。这个总体的最小值就是我们要求的东西。
![](https://cdn.luogu.com.cn/upload/image_hosting/h4q02wr8.webp)  
那如果**不考虑**每一段最多为 $w$ 的限制，我们可以贪心的去考虑，因为从 $1$ 至 $n$ 每一个元素至少要被加一遍并且每一段最大值减去最小值一定是一个非负整数。所以把整个序列设为一段一定是**最不劣**的。

那如果**考虑**每一段最多为 $w$ 的限制，就会发现贪心就变成假解了，于是我们考虑 $\operatorname{dp}$。  
从上面的图可以获取灵感，如果给他横着切似乎就可以设计状态了，就像这样。
![](https://cdn.luogu.com.cn/upload/image_hosting/fklt08uf.webp)
我们发现，每一个颜色都是一个 $a[j]$ 至 $a[n]$ 的子序列。  
那就可以设计状态了：$dp_i$ 表示从 $i$ 至 $n$ 的颜色下面一刀切掉，不管下面的最小花费。

状态都有了，那转移也十分的简单，因为与上一个颜色的左端点的差距即为一个段落，那可以直接从段落之和小于 $w$ 的所有地方转移过来。

即转移方程 $dp[i]=pre[n]-pre[i-1]+\min\limits_{\substack{1\le j\le i-1\\ \sum_{k=j}^{i-1} va[k]\le w}}\left(dp[j]+\max_{k=j}^{i-1}va[k]-\min_{k=j}^{i-1}va[k]\right)$

我相信正常人都看不懂。于是可以我们用可爱的语文表达式来表示：  
对于每个状态 $dp_i$，从 $i-1$ 向左枚举一个段 $[j,i-1]$，要求这段的总和不超过 $w$。这段的代价是段内最大值减最小值，也就是极差。 转移候选 $ans$：转移前的状态 $dp[j]$，加上当前段极差，再加上 $a_i$ 至 $a_n$ 的和，所有候选 $ans$ 中取最小值作为 $dp[i]$。

要注意要多枚举到 $n+1$ 不然最后一个一定会单独开一组。

剩下的就很简单了，看不懂文字的就看代码，但是注意：**十年OI一场空，不开long long见祖宗**。

```cpp line-numbers
#include<bits/stdc++.h>
#define ll long long
#define IOS ios::sync_with_stdio(0);cin.tie(0);cout.tie(0)
using namespace std;
const int INF = 1e9;
const ll LL_INF = 1e18;
int n, w;
ll dp[100005], pre[100005];
signed main() {
    IOS;
    freopen("group.in", "r", stdin);
    freopen("group.out", "w", stdout);
    cin >> n >> w;
    vector<ll>va(n + 5);
    int sumva = 0;
    for (int i = 1;i <= n;i++) {
        cin >> va[i];
        sumva += va[i];
        pre[i] = pre[i - 1] + va[i];
    }
    dp[1] = sumva;
    for (int i = 2;i <= n + 2;i++){
        ll sum = 0;
        ll ans = LL_INF;
        ll minn = LL_INF;
        ll maxn = 0;
        int j = i - 1;
        while (sum + va[j] <= w && j >= 1){
            sum += va[j];
            minn = min(minn, va[j]);
            maxn = max(maxn, va[j]);
            ans = min(ans, dp[j] + maxn - minn + pre[n] - pre[i - 1]);
            j--;
        } 
        dp[i] = ans;
    } 
    cout << min({dp[n], dp[n + 1]})  << '\n';
    return 0;
}
```
