这篇文章用于检查 Hugo + PaperMod 的 Markdown 渲染。重点是**普通代码块、带行号代码块、独立代码、普通表格和宽表格**。这不是正式文章，可以在测试完成后删除。

## 1. 行内代码

行内代码应该留在当前文字行内，例如 `vector<int> a = {1, 2, 3};`，不应该变成整块代码，也不应该出现单独的背景大框。

## 2. 普通 C++ 代码块

下面的代码块不要求显示行号，应该有完整的代码背景、圆角和语法高亮。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> values = {1, 2, 3, 4, 5};
    for (int value : values) {
        cout << value << ' ';
    }
    cout << '\n';
    return 0;
}
```

代码块之后的文字应该恢复正常段落宽度和行距，不应继续留在代码背景里面。

## 3. 带行号的 C++ 代码块

这个围栏使用项目预处理器支持的 `line-numbers` 标记。预处理后应转换成 Hugo Chroma 的行号设置。

```cpp line-numbers
#include <iostream>

int main() {
    const int answer = 42;
    std::cout << answer << '\n';
    return 0;
}
```

检查重点：行号应该可见；行号与代码之间不应出现粗黑边框；代码不能被挤压到容器之外；横向滚动只应发生在代码容器内部。

## 4. 其他语言的独立代码块

```python
from math import factorial

for n in range(1, 6):
    print(n, factorial(n))
```

```powershell
$items = 1..5
$total = ($items | Measure-Object -Sum).Sum
Write-Output "sum = $total"
```

这里测试连续出现不同语言的代码块时，两个块应各自拥有独立的边框和背景，不应粘在一起。

## 5. 普通表格

| 项目 | 预期结果 | 当前状态 |
|:--|:--|:--:|
| 普通代码块 | 背景与圆角正常 | 待检查 |
| 行号代码块 | 行号可见、无黑色边框 | 待检查 |
| 行内代码 `x + y` | 保持在文字行内 | 待检查 |
| 表格边框 | 细且清晰，不出现粗黑框 | 待检查 |

表格应和正文对齐。单元格文字不能溢出页面；在窄屏幕上，宽表格可以在自身区域横向滚动，不应撑宽整个页面。

## 6. 含行内代码和链接的表格

| 命令 / 内容 | 用途 | 备注 |
|---|---|---|
| `hugo server` | 本地预览 | 开发服务器 |
| `node scripts/luogu-markdown-preprocess.mjs` | 转换洛谷 Markdown 标记 | 从 `content` 生成 `content-luogu` |
| [Hugo 文档](https://gohugo.io/) | 查阅构建配置 | 外部链接应正常显示 |

## 7. 宽表格

| 编号 | 组件 | 桌面端检查项 | 窄屏检查项 | 备注 |
|---:|---|---|---|---|
| 1 | 普通代码块 | 容器宽度、内边距、语法高亮 | 代码可在容器内部横向滚动 | 不应出现额外的内层白框 |
| 2 | 行号代码块 | 行号与代码对齐 | 行号区不应挤占过多宽度 | 分隔线应细而浅 |
| 3 | 普通表格 | 表头、单元格、边框正常 | 表格自身横向滚动 | 页面整体不应横向溢出 |
| 4 | 独立代码块 | 每块有独立背景和圆角 | 代码文字不应被裁切 | 相邻代码块之间留有间距 |

## 8. 代码块与表格前后相邻

```text
上方是一个独立代码块。
下面紧接表格。
```

| 测试位置 | 预期 |
|---|---|
| 代码块后 | 正常显示表格 |
| 表格后 | 正常显示段落 |

表格结束后，这段文字不应继续沿用表格样式，也不应出现多余的黑色边框。

## 9. 独立数学公式（辅助检查）

行内公式：\(a^2 + b^2 = c^2\)。

独立公式：

\[
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\]

如果公式能显示但代码块或表格样式异常，说明需要重点检查代码块和表格 CSS；如果公式也不显示，则还要检查 KaTeX 的加载与自动渲染。

## 10. 检查清单

- [ ] 行内代码没有变成块级代码。
- [ ] 普通 C++ 代码块背景、圆角和高亮正常。
- [ ] 带行号代码块显示行号，没有粗黑边框。
- [ ] Python 与 PowerShell 代码块彼此独立。
- [ ] 普通表格边框、对齐和文字换行正常。
- [ ] 宽表格只在表格自身区域横向滚动。
- [ ] 代码块与表格相邻时，样式没有串到下一个组件。
- [ ] 行内公式和独立公式正常渲染。
