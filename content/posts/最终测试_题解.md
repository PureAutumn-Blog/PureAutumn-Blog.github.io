## 题意概述
有一只喜欢玩《明日方舟》的猫猫，为了迎接周年庆开了 $3 \times 10^5$ 个账号。  

为了决定剩余账号的优先级，猫猫给每个账号安排了两项最终审核，每项审核都有 $50\%$ 的概率通过，且互不影响。如果某项审核没有通过，那么该项对应的价值就会直接归零。猫猫根据两项审核后的总价值给账号排名，排名为比他价值大的账号数加一。     

猫猫想知道，每个账号的期望排名分别是多少。但这只满脑子都是周年庆、熬穿了的猫猫已经算不动了，于是出了这道题。

## 思路:

每个账号，设两项价值分别为 $a_i,b_i$。经过最终审核后，其总价值只有四种可能：$0,a_i,b_i,a_i+b_i$，且每种情况出现的概率均为 $\frac14$。

一个账号的排名等于总价值严格大于它的账号数量加一。因此，我们只需要计算每种可能情况下，有多少其他账号的总价值比它大，再根据概率计算期望排名。

对于账号 $i$ 的一种可能总价值 $x$，考虑另一个账号 $j$ 的一种可能总价值 $y$。如果 $y>x$，那么当这两种情况同时发生时，账号 $j$ 就会比账号 $i$ 多贡献一次排名。

由于每项审核通过的概率均为 $\frac12$，且相互独立，一个账号出现指定可能总价值的概率为 $\frac14$。不同账号之间的审核也相互独立，因此这两种情况同时发生的概率为

$ \frac14\times\frac14=\frac1{16}. $

所以，每统计到一个严格大于 $x$ 的可能总价值，就给期望排名增加 $\frac1{16}$。注意，相等的情况不计入贡献。

## 实现:

将所有账号的可能总价值存入数组 $b$，并从小到大排序。

对于账号 $i$ 的每种可能总价值 $x$，使用 `upper_bound` 找到数组中第一个严格大于 $x$ 的元素，从而得到整个数组中严格大于 $x$ 的元素数量。

但这个数量包含账号 $i$ 自身的可能总价值，因此还需要枚举它的四种可能值，将其中严格大于 $x$ 的值逐一减去。

最后，将剩余数量除以 $16$，累加到初始值为 $1$ 的答案中，即可得到该账号的期望排名。

## 代码:

```
#include <bits/stdc++.h>
#define ll long long
#define IOS ios::sync_with_stdio(0);cin.tie(0);cout.tie(0)
using namespace std;

int main() {
    IOS;
    freopen("final.in", "r", stdin);
    freopen("final.out", "w", stdout);

    int n;
    cin >> n;
    vector<array<int, 4>> a(n);
    vector<int> b;

    for (int i = 0; i < n; i++) {
        int x, y;
        cin >> x >> y;
        a[i] = {0, x, y, x + y};
        for (int j = 0; j < 4; j++) {
            b.push_back(a[i][j]);
        }
    }

    sort(b.begin(), b.end());
    vector<double> ans(n, 1.0);

    for (int i = 0; i < n; i++) {
        for (int x : a[i]) {
            int cnt = b.end() - upper_bound(b.begin(), b.end(), x);
            for (int y : a[i]) {
                if (y > x) cnt--;
            }
            ans[i] += cnt / 16.0;
        }
    }

    cout << fixed << setprecision(10);
    for (double x : ans) {
        cout << x << '\n';
    }
    return 0;
}
```

## 复杂度分析
时间复杂度为 $O(n\log n)$，瓶颈在于排序和二分查找。
